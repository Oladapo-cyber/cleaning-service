                        **CSS FLEXBOX**
Setting the display to flex creates 2 invisible axis. The main axis(->) and the cross axis(downwards).
-By default the main axis is horizontal, so when we say display flex; it aligns the items horizontally.
-If we want, we could change the main axis to be vertical(down) using the flex-direction property and setting it to column. With this, the items are aligned in column.
-After knowing the direction of our main axis, we can align the items along the main axis using the justify-content property; The default is flex-start, so nothing happens. So if we set it to flex-end, the items would be pushed to the end of the alignment.
Center would center the items in the middle, space-between would evenly distribute the items in between the first and the last item, space-around is similar to space between but now, the edges would also have spacing to them, space-evenly would evenly distribute spaces between all the items. 
-Justify content is used for aligning items on the main axis, but we can also align items along the cross axis using the align-items property. Flex-start places items at the start of the cross axis, flex-end places items at the end of the cross axis, center aligns items at the middle of the cross axis, and baseline would align items so that the baseline text of each items is aligned.  

-By default, flex items would all try to fit into one line. When you add more items into the container, the items would start crushing each other. To fix this, we could make our items wrap with the flex-wrap property, by default it's set to nowrap, but if we set it to wrap, we see that instead of them to crush each othwer, the excess items move onto the next line.
-When items are set to wrap, a new property is unlocked. The align-content property, this only works when we have the flex-wrap set to wrap, and when we have items wrapping.
- This property allows us to have everything aligned on the cross axis. The values that go here are pretty much the same as the justify-content property. If the items are touhing each other, we could use the gap property on the container to add gaps between each items.
-All the flexbox properties above are meant for the container holding the items, but then there are some properties that could be used within the direct children of the container. 

-We can select an item in a container by it's class name and give it a property of flex-grow. The flex-grow property takes a unitless value which serves as a proportion, and what it does is allow an item to grow if there is enough space for it.
-Another property to use is flex-shrink, and this also takes a unitless value. And it defines how fast one item shrinks in comparison to the others. i.e if we set item 1 to flex-shrink: 5; it shrinks much faster than the other items. If we don't want an item to shrink at all, we can set it to flex-shrink: 0 and it won't shrink.
-flex-basis defines the size of an item before the remaining space is distributed. Basically if your item already has a size like a width, but you want to overwrite that size with something else; then you use flex-basis. For example, if an item has the width of 150px and you want to overwrite that, you use flex-basis and set the value to what you need the new width of the item to be. eg flex-basis: 300px. But if you set it to 0, you're Basically shrinking it to the max.
-The property flex is the shorthand for the flex-grow, flex-shrink and flex-basis combined,but the second and third parameters for the flex are optional. i.e when you set the flex to have only one value, the other 2 optional values are set automatically and inteligently.
-Another property is the align-self, and this overwrites the value you set in the align item on the container, but for an individual item. i.e if you have align item set to flex-start on the container but you want the first item to be aligned center on the cross axis,you can use the align-self property to overwrite what you have set in the container and have the individual item placed in the center. Other than center, you can also have flex-start, flex-end and baseline as possible values.
-The last property is the order property; by default the items are laid out in the order of the html,  we can use this property to change the order in which the items appear. That is if we want the last item to appear first, we should give it the order property and set the value to -1. It's set to -1 because the default value of this property is 0, i.e all items have an order value set to 0 by default so to have the third item appear first we set the value to -1 And if we want the first item to appear last, we set the order property to 1.
-However, the order property isn't one to always use unless you absolutely have to as it messes with the semantics and the accsessibility of the html
